# SeaPup Power System Design

This repository contains KiCad design files for the SeaPup autonomous underwater vehicle power system.

The current work focuses on the power switching structure for the control system, ESCs, and thrusters, including the system switch and kill switch behavior.

## Project Context

This project is part of an autonomous underwater vehicle design project and is also connected to the University of Seoul Future Design Semester research internship.
